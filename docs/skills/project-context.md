# Project Context Skill

Use this when orienting to Taalim or deciding whether work belongs in the current issue.

## Read
- `PROJECT_MEMORY.md`
- `STATUS.md`
- `docs/GOALS.md`
- `docs/ROADMAP.md`
- the assigned issue and dependencies

## Rules
- Product/business rules come from Issue #1 and accepted ADRs, not guesses.
- The repository is pre-development until foundation issues are completed.
- Keep task handoffs in issues/PRs rather than expanding global memory.
- If source documents, issue text, and ADRs conflict, surface the conflict and request a decision.
